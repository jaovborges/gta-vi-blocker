Correção dos avisos que apareciam sobre outros posts no feed do X/Twitter.

- O bloqueio usa o tweet como contêiner e preserva a célula usada pelo X para posicionar o post.
- O aviso fica na mesma célula do tweet, acompanhando seu posicionamento no feed.
- Se o site mover um post, o aviso é realocado; se remover o post, o aviso também é removido.
- Mostrar e ocultar novamente continuam vinculados somente ao tweet selecionado, sem gerar avisos extras.

Validação: 60 testes automatizados e 17 verificações de integração Chromium aprovados, incluindo coordenadas de avisos em um feed virtualizado de teste, movimento e descarte de tweets. Não se trata de uma sessão autenticada no X real.

Para atualizar uma instalação local, abra `chrome://extensions`, clique em **Recarregar** no GTA VI Blocker e depois recarregue a aba do X. Se instalou a partir de um ZIP, extraia primeiro esta versão sobre a pasta da extensão ou carregue a nova pasta extraída. As configurações são preservadas ao recarregar a mesma instalação.
